Help for BrickStep on iPhone and iPad

Supported Files

BrickStep opens local .io, .ldr, and .mpd files. Tap Open Model and choose a file from Files or another document provider.

Detailed Geometry

For complete part geometry, tap LDraw Library and select the root of an LDraw installation that contains the parts and p folders. Access is limited to the folder selected by the user.

Gestures

Drag with one finger to orbit, pinch to zoom, and drag with two fingers to pan. Double-tap the viewport to reset the camera.

Large Models

BrickStep uses local resource safeguards for large files. If a model exceeds a limit, the app shows an error instead of continuing indefinitely. Very large historical geometry may use simplified display geometry.

Studio Content

Studio instruction page layouts, callouts, and custom instruction graphics are not currently rendered. Step order and added parts are derived from embedded LDraw data.
